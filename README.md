An **EMG-controlled robotic prosthetic hand** designed to reproduce basic finger movements using electrical signals generated by forearm muscles.

Surface EMG electrodes capture muscle activity, which is processed by an **ESP32 microcontroller** to generate open/close commands for five servomotors controlling a 3D-printed articulated hand.

Additionally, five **ACS712 current sensors** monitor individual servo currents to detect mechanical obstructions, identify blocked fingers, and provide motor protection.

## 1. Project Overview

The objective of this project is to develop an intelligent robotic prosthetic hand capable of interpreting muscle activity and translating it into mechanical finger movements.

The system uses surface Electromyography (EMG) electrodes positioned on the forearm to acquire electrical signals generated during muscle contraction.

These signals are processed by an ESP32 microcontroller using digital signal-processing techniques to distinguish between relaxed and contracted muscle states.

Based on the detected muscle activity, the controller generates movement commands for five servomotors responsible for actuating the individual fingers.

To improve operational safety, each servo is equipped with an ACS712 current sensor that monitors its electrical consumption and detects abnormal current conditions associated with mechanical obstruction or blocked finger movement.

The project combines embedded firmware development, analog signal acquisition, real-time signal processing, actuator control, current monitoring, and mechanical prototyping.

## 2. Main Features

- EMG signal acquisition through surface electrodes.
- 1 kHz analog signal sampling using the ESP32 ADC.
- Baseline removal, signal rectification, and low-pass filtering.
- EMG envelope extraction for muscle activity detection.
- Automatic calibration based on resting and contracted muscle states.
- Hysteresis-based detection to reduce false triggering.
- Confirmation window and hold-time logic for stable command generation.
- Independent control of five servomotors.
- Slew-rate-limited servo movement for smoother finger actuation.
- Individual current monitoring using five ACS712 sensors.
- Servo current zero-offset calibration at startup.
- Mechanical obstruction and motor stall detection.
- Soft-stall and hard-overload protection mechanisms.
- Serial communication for real-time monitoring and manual control.
- Hardware-independent signal-processing and current-monitoring modules.
- Host-side unit testing of embedded processing logic.
- CAD-designed and 3D-printed articulated prosthetic hand.

- Power distribution and protection must be designed to avoid voltage drops and electrical interference.

## 5. System Architecture

The system follows a modular architecture composed of five main functional stages.

### A. EMG Signal Acquisition

Surface electrodes positioned on the forearm capture electrical activity generated by muscle contractions.

The EMG sensor board amplifies and conditions the acquired signals before forwarding them to the ESP32 ADC.

The microcontroller samples the analog signal at a configured frequency of 1 kHz.

### B. EMG Signal Processing

The acquired signal is processed to extract meaningful muscle activity information.

The processing sequence includes:

- Baseline removal to reduce the effect of the signal offset.
- Full-wave rectification to obtain the signal magnitude.
- Low-pass filtering to smooth the rectified signal.
- Envelope extraction to estimate muscle activation intensity.

The resulting envelope provides a more stable representation of muscle activity for command detection.

### C. Muscle Activity Detection

The processed EMG envelope is compared against thresholds established through an automatic calibration procedure.

The calibration process includes two stages:

- Resting stage: measures baseline muscle activity.
- Contraction stage: measures the signal response during muscle activation.

A hysteresis-based detection mechanism combined with a confirmation window distinguishes between relaxed and contracted states.

This reduces unwanted movements caused by electrical noise or short-duration signal disturbances.

### D. Finger Actuation

The ESP32 generates movement commands for five servomotors.

Each servo controls an individual finger through the mechanical transmission system integrated into the 3D-printed hand.

Slew-rate limiting is implemented to avoid abrupt servo movements and provide smoother finger actuation.

### E. Current Monitoring and Protection

Each servomotor is monitored by an individual ACS712 current sensor.

The measured current is filtered and evaluated to identify abnormal operating conditions.

The protection logic distinguishes between:

- Normal operation: servo current remains within the expected operating range.
- Soft stall: sustained abnormal current indicates possible mechanical obstruction.
- Hard overload: excessive current triggers a stronger protection response.

The system can freeze the affected finger during a detected stall or detach the corresponding servo when a hard overload is identified.

An initial current inrush period following movement commands is ignored to reduce false stall detection.

## 7. EMG Signal Processing

The EMG processing module transforms the raw analog signal into a stable representation of muscle activation.

### Signal Processing Stages

| Stage | Function |
|---|---|
| Signal Acquisition | Samples the analog EMG signal at 1 kHz |
| Baseline Removal | Removes the DC component and resting offset |
| Rectification | Converts the signal into a positive magnitude |
| Low-Pass Filtering | Reduces rapid signal fluctuations |
| Envelope Extraction | Produces a smoothed representation of muscle activity |
| Threshold Detection | Determines whether muscle contraction is detected |

### Automatic Calibration

The system uses an automatic calibration procedure to adapt the detection thresholds to the measured muscle signal.

The calibration sequence includes:

1. Measuring the EMG signal while the forearm muscles are relaxed.
2. Measuring the signal during a deliberate muscle contraction.
3. Establishing the detection thresholds from the measured signal levels.
4. Enabling muscle-controlled operation.

### Hysteresis and Confirmation Logic

A hysteresis-based threshold mechanism is used to avoid unstable switching when the EMG envelope fluctuates around the detection threshold.

A 200 ms confirmation window is used to validate detected muscle activity, while a 300 ms hold-time mechanism helps prevent unwanted command switching.

These parameters are configurable according to the actual firmware implementation.

## 8. Servo Control and Current Monitoring

The actuation and protection modules manage finger movement while monitoring the electrical behavior of each servomotor.

### A. Five-Finger Servo Control

Five servomotors are used to control the movement of the prosthetic hand.

The controller supports:

- Individual finger actuation.
- Open and close movement commands.
- Independent servo positioning.
- Slew-rate-limited movement.
- Per-finger direction inversion for different mechanical mounting orientations.

### B. ACS712 Current Monitoring

Each servo is connected to an individual ACS712 current sensor.

The measured analog signals are converted into current measurements and evaluated by the current-monitoring module.

At startup, the system performs zero-offset calibration to establish the reference current level for each sensor.

### C. Stall and Overload Detection

The current-monitoring logic evaluates servo current to identify abnormal operating conditions.

| Condition | Detection Method | System Response |
|---|---|---|
| Normal Operation | Current within the expected range | Normal servo operation |
| Soft Stall | Sustained abnormal current | Freeze the affected finger |
| Hard Overload | Current exceeds the configured protection limit | Detach the affected servo |
| Startup Inrush | Current transient immediately after a command | Temporarily ignored |

The detection thresholds and timing parameters must be calibrated according to the actual servomotors, mechanical load, and sensor characteristics.

## 9. Serial Communication and Monitoring

A UART serial interface provides a debugging and monitoring mechanism between the ESP32 and a computer.

The serial interface supports several commands for system operation and testing.

### Available Serial Commands

| `i` | Display current sensor telemetry |
| `o` | Force hand opening |

**Serial Configuration**

The serial interface allows the developer to monitor EMG signal behavior, inspect servo current measurements, test movement commands, and investigate protection events.

The mechanical structure consists of five articulated fingers connected to a palm assembly.

Servomotors are mounted inside the hand and provide the mechanical actuation required for opening and closing the fingers.

The forearm socket provides the mounting structure for integrating the prosthetic hand with the user's forearm.

The mechanical design focuses on:

- Five-finger articulation.

## 13. Build and Flash

The firmware can be compiled and uploaded using PlatformIO.

### Requirements

- ESP32 development board.
- USB connection to the computer.
- Visual Studio Code with the PlatformIO extension, or PlatformIO Core.
- Appropriate ESP32 board support.

### Build Instructions

Clone the repository:

```bash
git clone https://github.com/wajih-dridi/NeuroHand-Smart-Prosthesis.git
```

Navigate to the project directory:

```bash
cd NeuroHand-Smart-Prosthesis
```

Compile the firmware:

```bash
pio run
```

Upload the firmware:

```bash
pio run -t upload
```

Open the serial monitor:

```bash
pio device monitor
```

The default serial communication speed is 115200 baud.

### Startup and Calibration Sequence

The firmware follows the following startup procedure:

1. Initialize the ESP32 peripherals.
2. Initialize and calibrate the ACS712 current sensors.
3. Allow the EMG signal to stabilize while the muscles remain relaxed for approximately 5 seconds.
4. Perform a deliberate muscle contraction for approximately 4 seconds when prompted.
5. Calculate the EMG detection thresholds.
6. Enable automatic EMG-based hand control.

For additional information, refer to:

- [Hardware Configuration](docs/hardware.md)
- [Calibration Procedure](docs/calibration.md)
- [Firmware Architecture](docs/firmware.md)
- [Safety Guidelines](docs/safety.md)
