# NeuroHand-Smart-Prosthesis-for-People-with-Amputated-Hands
Development of a muscle signal (EMG) controlled prosthetic arm using an ESP32 board for signal processing and servomotor control.  The project integrates biological data acquisition via electrodes, signal analysis with an ACS712 sensor, and articulated movement control through a well-defined 3D-printed mechanical design.
